# AGENTS.md

Cross-agent pointer file for Codex, Gemini CLI, and similar coding assistants.

## Purpose

- Provide a neutral entrypoint for non-Claude assistants.
- Mirror where architecture, design, and coding constraints live.

## Source of truth

Assistants should prioritize:
1. `README.md` for repository goals and structure.
2. `DESIGN.md` for UI and token conventions.
3. `.cursor/rules/*.mdc` for domain-specific implementation rules.
