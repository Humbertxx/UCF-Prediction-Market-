# Bloomknights

Bloomknights is an AI-assisted prediction market platform with:
- a Python backend for market logic, trading, bots, and realtime events
- a TypeScript frontend for market participation and admin workflows
- shared project guidance for AI coding agents

## What this repository is for

This repository is the primary implementation context for:
- product requirements and architecture direction
- backend and frontend code organization
- AI-agent operating rules and role-specific constraints

## Folder overview

- `backend/`: API, domain logic, AMM engine, bots, AI insight generation, realtime broadcasting.
- `frontend/`: UI, hooks, API clients, market pages, leaderboard, admin panel.
- `.cursor/rules/`: Cursor-specific coding rules by domain.
- `CLAUDE.md` and `AGENTS.md`: compatibility pointers for different coding assistants.
- `DESIGN.md`: design tokens and UI consistency guidance.

## Implementation status

This scaffold defines intended responsibilities for each file so feature development can proceed with clear boundaries and minimal ambiguity.
